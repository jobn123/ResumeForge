# ResumeForge —— 可编辑简历生成器（独立项目）

把「简历编辑器」从单一 HTML 文件抽离出的**独立前端项目**：可直接在浏览器打开编辑、实时预览、换主题/模板、拖拽排序模块、导出 PDF / PNG / Word / HTML。

> 纯前端、零构建、零后端。所有数据保存在浏览器 `localStorage`，不上传任何服务器。

## 快速开始

```bash
# 方式一：直接用浏览器打开
open index.html        # macOS
# 注意：Word 导出需读取本地 CSS，建议用本地服务器以避免 file:// 限制

# 方式二：本地静态服务器（推荐，Word/PDF 导出更稳）
python3 -m http.server 8765
# 然后访问 http://127.0.0.1:8765
```

## 功能一览

- **实时编辑**：点击任意文字即可修改；悬停条目出现 × 删除，绿色按钮可新增。
- **编辑 / 预览切换**：预览态隐藏所有编辑控件与分页参考线。
- **分页参考线**：编辑/预览均显示红色虚线分页标记，方便控制篇幅。
- **拖拽排序**：模块（章节）之间、模块内条目（工作/项目/技能/要点）均可拖拽重排。
- **模块显隐 / 自定义**：每个模块可隐藏或删除；可一键新增自定义模块。
- **全局样式面板**：字体族、正文字号、行距、主题色、密度（紧凑/宽松）实时调节。
- **5 套主题 + 2 套版式**：靛蓝/海洋蓝/暖阳橙/森林绿/石板灰；经典单列 / 现代居中。
- **自动保存**：编辑内容实时存入 `localStorage`，刷新不丢失。
- **重置为初始数据**：一键清空全部修改，恢复内置示例简历（林墨）与默认样式（带二次确认弹窗）。
- **多格式导出**：PDF、PNG、Word(.doc)、干净 HTML、一键打印。

## 后续可扩展（已预留接口）

- **更多版式**：在 `base.css` 增加 `[data-template="sidebar"]` 双栏布局（左信息栏 + 右经历）。
- **云端同步**：把 `storage.js` 的 localStorage 替换为可选的后端 API。
